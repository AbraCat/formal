# Formal Languages Library

Библиотека на Python для работы с регулярными выражениями и конечными автоматами.

## Установка зависимостей
```bash
python -m venv venv
source venv/bin/activate
pip install -e ".[dev]"
```

## Запуск
Перед запуском библиотеки нужно зайти в venv:
```bash
source venv/bin/activate
```

Для запуска используется команда `formal`. Для вызова конкретных алгоритмов используются подкоманды. Подкоманды, работающие с автоматами, сериализуют их в файл. Также подкоманды могут рисовать получившийся автомат с помощью Graphviz. Имеющиеся подкоманды:
- `make_nfa`. Преобразует регулярку в НКА алгоритмом Томпсона. Регулярка задаётся флагом `--regex`.
- `determinize`. Детерминизирует НКА в ДКА алгоритмом построения подмножеств.
- `normalize`. Минимизирует ДКА в МПДКА алгоритмом Хопкрофта.
- `process`. Выполняет цепочку преобразований: регулярка -> НКА -> ДКА -> МПДКА.

Имеющиеся флаги:
- `--input`. Задаёт файл с входным автоматом.
- `--output`. Задаёт файл с выходным автоматом.
- `--draw`. Задаёт файл с изображением выходного автомата.

Примеры:
```bash
formal process --regex="a(a(ab)*a(ab)*+b)*"
formal determinize --input="txt/nfa.txt" --output="txt/dfa.txt" --draw="png/dfa.png"
```
